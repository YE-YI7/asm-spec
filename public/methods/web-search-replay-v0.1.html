ASMMethod · v0.1 draft

Web search replay

A deterministic, no-network test of request validation, evidence-bound selection, provider response normalization, and decision/outcome receipts.

Input
Private query commitment, authorized candidates, effective policy, budget, replay payload.
Output
Normalized URLs, titles and snippets plus a JCS-bound decision and outcome.
Failure coverage
Empty result, malformed result, auth failure, billing block, rate limit and timeout.
Not measured
Live quality, p50/p95 latency, reliability, settled cost and owner preference fit.
Replay is not a live benchmark. Fixture payloads contain no API key, real customer query, or claimed provider measurement.
Reproduce from sourceInspect a replay labelService cards
Method version and evidence dates remain visible so a later live run cannot silently inherit replay claims.
