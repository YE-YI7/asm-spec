# Product-facing sample library

This directory contains 30 source-linked selection examples. It is a curated
sample library, not a real-time marketplace. As of 2026-08-16, all 30 entries
are 31–90 days past `provenance.last_verified_at`; 20 are `self_reported` and
10 are `manual_verified`.

Stale entries remain useful for schema and integration tests, but must not be
presented as current provider facts until reviewed. See
[`docs/data-quality/README.md`](../docs/data-quality/README.md).
